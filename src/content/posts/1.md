GitHub 的 HTTPS 时常连不上，SSH 走 22 端口要稳得多。与其每次 clone 都手动改地址，不如让 git 自动把 `https://github.com/` 前缀改写成 SSH 形式。

## 配置

```bash
git config --global url."git@github.com:".insteadOf "https://github.com/"
```

配好之后，`git clone https://github.com/user/repo.git` 实际走的是 SSH，前提是本机公钥已经加到 GitHub 账号里。

## 验证与撤销

```bash
# 查看当前生效的 url 改写规则
git config --global --get-regexp "url\."

# 撤销
git config --global --unset url."git@github.com:".insteadOf
```
