在终端里翻到一个深层目录（比如某个项目的构建产物），想用图形界面对着文件操作时，不用再从 `C:\` 一层层点下去。

## 打开当前目录

```bash
explorer .
```

`explorer` 是 Windows 自带的命令，`.` 表示当前目录。终端停在哪儿，资源管理器就开在哪儿。

## 几个常用变体

```bash
explorer ..          # 打开上一级目录
explorer .\dist      # 打开当前目录下的 dist 文件夹
explorer C:\Users    # 打开绝对路径
```

## 注意

`explorer.exe` 成功打开窗口时**返回值也是 1**，所以在脚本里判断成败不能看退出码，否则会误判成失败。用它做跳转就行，不要拿来做存在性检查。
