Windows 会给每个快捷方式（`.lnk`）左下角叠一个小箭头。它由注册表 `Shell Icons` 里的 29 和 77 号覆盖图标决定，把这两项指向一个透明图标，再重建图标缓存就干净了。

## 清除箭头

新建一个 `.bat` 文件，粘贴下面的内容，右键"以管理员身份运行"：

```bat
reg add "HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\Shell Icons" /v 29 /d "%systemroot%\system32\imageres.dll,197" /t reg_sz /f
reg add "HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\Shell Icons" /v 77 /d "%systemroot%\system32\imageres.dll,197" /t reg_sz /f
taskkill /f /im explorer.exe
attrib -s -r -h "%userprofile%\AppData\Local\iconcache.db"
del "%userprofile%\AppData\Local\iconcache.db" /f /q
start explorer
pause
```

脚本会重启 `explorer.exe`，屏幕会闪一下、任务栏短暂消失，属正常现象。

## 恢复箭头

想改回默认外观，管理员身份运行下面这段：

```bat
@echo off
reg delete "HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\Shell Icons" /v 29 /f
reg delete "HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\Shell Icons" /v 77 /f
taskkill /f /im explorer.exe
attrib -s -r -h "%userprofile%\AppData\Local\iconcache.db" 2>nul
del "%userprofile%\AppData\Local\iconcache.db" /f /q 2>nul
attrib -s -r -h "%localappdata%\IconCache.db" 2>nul
del "%localappdata%\IconCache.db" /f /q 2>nul
attrib -s -r -h "%userprofile%\AppData\Local\Microsoft\Windows\Explorer\iconcache*" 2>nul
del "%userprofile%\AppData\Local\Microsoft\Windows\Explorer\iconcache*" /f /q 2>nul
start explorer
pause
```

> 提示：两段脚本都必须以管理员身份运行，否则写 `HKLM` 会报拒绝访问。改完如果箭头还在，注销一次或重启资源管理器即可。
