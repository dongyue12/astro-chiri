## 字母含义

| 字母 | 含义 |
| --- | --- |
| U | Up → 顶层 |
| F | Front → 前层 |
| R | Right → 右层 |
| D | Down → 底层 |
| B | Back → 后层 |
| L | Left → 左层 |
| M | LR 的中层 |
| E | UD 的中层 |
| S | FB 的中层 |

## 顺逆时针

- 单个大写字母：该层顺时针旋转 90°
- 单个大写字母带 `'` 符号：该层逆时针旋转 90°
- 小写字母：同时转动两层
