WinGet 默认走微软的 CDN，国内拉包经常卡住或超时。换成南京大学镜像后，`winget install` 和 `winget upgrade` 都会顺很多。

## 换源

先删掉原源：

```powershell
winget source remove winget
```

再添加南京大学镜像：

```powershell
winget source add winget https://mirror.nju.edu.cn/winget-source
```

最后确认一下当前源列表：

```powershell
winget source list
```

## 恢复默认

想换回官方源：

```powershell
winget source reset winget
```
