# 文章格式说明

本目录（`src/content/blog/待处理文章/`）是**草稿暂存区**。

它在 `src/content.config.ts` 里被显式排除：

```ts
pattern: ['**/*.{md,mdx}', '!**/待处理文章/**']
```

所以放这里的文件**不会发布、也不会走 frontmatter 校验**，可以直接丢 Obsidian 导出的原始稿。
处理完成后再移到上一级 `src/content/blog/`，按下面的规则正式发布。

> 注意：文档本身就是靠这条排除规则才不会被当成文章。如果哪天把排除规则去掉了，
> 本文档会因为缺 frontmatter 让构建报错，把本文档移出 `src/content/blog/` 即可。

---

## 一、命名

```
<编号>.<简短标题>.md          例：19.vscode快捷键.md
```

- **编号决定 URL**：`19.vscode快捷键.md` → `https://dongyue.org/blog/19/`
- 编号 = 现有最大编号 + 1，不跳号、不重复
- 编号和标题之间用 `.` 分隔
- 标题里不要有空格（`9. VSCode 右键菜单乱码.md` 这种是老写法，新文章避免）
- 文件名尽量短，中英文都行，与已有风格一致

## 二、frontmatter（发布时必须写）

```yaml
---
title: 'VSCode 快捷键'
pubDate: '2026-09-23'
---
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `title` | 是 | 页面标题，用于 `<h1>` 和 `<title>` |
| `pubDate` | 是 | `'YYYY-MM-DD'`，**要带引号**；按编号顺序递增 |
| `description` | 否 | 目前全站都没用，不写则用站点默认描述 |
| `updatedDate` | 否 | 写了会在日期后面多显示一行「更新于 …」 |

⚠️ **正文里不要再写一遍 `# 标题`**。页面标题由 `PostLayout` 渲染成 `<h1>`，重复写会出现两个一级标题。

## 三、正文写法

- 标题层级从 `##` 或 `###` 开始（h1 留给布局）
- 列表统一用 `- `，不要用 Obsidian 的 `*   `
- 代码块标注语言：` ```bash ` / ` ```powershell ` / ` ```jsonc ` / ` ```text `
- 表格用标准 Markdown 表格

## 四、图片

图片统一放同级 `assets/` 目录，**只用这一种写法**：

```markdown
![图片说明](./assets/文件名.png)
```

不要用下面这三种：

| 不要用 | 原因 |
| --- | --- |
| `data:image/png;base64,...` | md 文件会膨胀到上百 KB，且无法被 Astro 优化 |
| `https://其他站点/xxx.png` | 依赖第三方，对方挂图文章就空了 |
| `<img src="assets/xxx.png">` | 裸 HTML，Astro 不会处理，路径会 404 |

新增图片：把图片文件放进 `assets/`，正文按上面的写法引用即可。
构建时自动转 WebP 并生成多档 `srcset`，不需要手动压缩。

## 五、Obsidian 导出后要清理的东西

| 现象 | 处理 |
| --- | --- |
| `1\.` `\[` `\]` `\*\*` | 去掉反斜杠 → `1.` `[` `]` `**` |
| `*   ` 开头的列表 | 改成 `- ` |
| 行尾空格、空行里的空格 | 删掉 |
| 内联的 `## 小标题` | 改成正常标题或加粗 |
| 外链莫名失效 | 检查是否被转义，例：`qq\_51173321` 实际是 `qq_51173321` |

## 六、处理流程

1. 草稿直接丢进本目录，原始 Obsidian 导出格式即可，不用先整理
2. 处理时依次做：定编号 → 补 frontmatter → 删重复 H1 → 清转义/列表 → 图片进 `assets/`
3. 移到上一级 `src/content/blog/`
4. 本地校验：

   ```powershell
   node node_modules/astro/bin/astro.mjs build
   ```

   （`pnpm build` 在当前环境会因为 pnpm 的依赖检查报 TTY 错误，直接用 astro 入口即可）
5. 提交推送
