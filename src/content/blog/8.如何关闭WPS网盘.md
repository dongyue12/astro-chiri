# 如何关闭 WPS 网盘 —— 删除资源管理器中的 WPS网盘 入口

> 适用环境：Windows 10 / 11 + WPS Office（国内版）
> 目标：移除文件资源管理器**导航窗格**和**"此电脑"**中的"WPS网盘"图标，且不影响 WPS Office 本身的正常使用。

---

## 一、背景

安装 WPS Office 后，文件资源管理器里会多出一个"WPS网盘"入口（侧边栏和"此电脑"里各一个）。WPS 客户端内的关闭开关藏得很深、部分版本甚至没有，卸载重装也不一定干净。最直接可靠的办法，是删除它在注册表 `NameSpace` 里注册的两个项。

**原理**：资源管理器在以下两个注册表键下枚举"额外位置"图标，WPS 安装时会把自己的 GUID 子项写进去——

| 注册表路径 | 控制的位置 |
| --- | --- |
| `HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\MyComputer\NameSpace` | "此电脑"里显示的附加项 |
| `HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Desktop\NameSpace` | 桌面 / 导航窗格的附加项 |

删掉这两个 WPS 的 GUID 子项，图标即消失。`HKLM`（HKEY_LOCAL_MACHINE）下虽有同名路径，但里面都是系统自带项（回收站、控制面板等），一般没有 WPS 的，**不需要动**。

本机（Win11 + WPS）实测查到的两个 GUID，仅供参考，**请以自己机器上查到的名称为准**：

| 位置 | GUID |
| --- | --- |
| 此电脑 | `{5FCD4425-CA3A-48F4-A57C-B8A75C32ACB1}` |
| 桌面/导航窗格 | `{7AE6DE87-C956-4B40-9C89-3D166C9841D3}` |

---

## 二、准备工作：备份注册表

> ⚠️ 删除注册表项之前务必备份，出问题时双击 `.reg` 文件即可还原。

手动方式：在 regedit 中右键 `NameSpace` 键 → **导出**，保存为 `.reg` 文件。

命令行方式（PowerShell）：

```powershell
reg export "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\MyComputer\NameSpace" "$env:USERPROFILE\Downloads\MyComputer-NameSpace-backup.reg" /y
reg export "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Desktop\NameSpace" "$env:USERPROFILE\Downloads\Desktop-NameSpace-backup.reg" /y
```

## 三、方法一：注册表编辑器手动删除

1. `Win + R` 打开运行，输入 `regedit` 回车。
2. 分别定位到以下两个路径（可直接复制粘贴到 regedit 顶部地址栏）：

   ```text
   计算机\HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\MyComputer\NameSpace
   计算机\HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\Desktop\NameSpace
   ```

3. 展开 `NameSpace`，找到与 WPS 相关的项（名称是一串 GUID）。**辨认方法**：
   - 选中 GUID 项后，一般看不到名字；去 `HKEY_CLASSES_ROOT\CLSID\{这个GUID}` 查看它的"默认"值，显示为 **WPS网盘** 的就是；
   - 或者直接用 regedit 的 `Ctrl + F` 搜索 `WPS网盘`。
4. 右键该 GUID 项 → **删除**。两个路径下各有一个 WPS 的项，都要删。
5. 刷新资源管理器（`F5`）看图标是否消失；如果没消失，重启 explorer：

   ```powershell
   taskkill /f /im explorer.exe
   start explorer.exe
   ```

## 四、方法二：PowerShell 一条龙（识别 + 备份 + 删除 + 刷新）

### 第 1 步：枚举 NameSpace 下的项，确认哪个是 WPS

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$roots = @(
  "HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\MyComputer\NameSpace",
  "HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\Desktop\NameSpace"
)
foreach ($r in $roots) {
  Write-Host "== $r"
  Get-ChildItem $r | ForEach-Object {
    $g = $_.PSChildName
    $n = (Get-ItemProperty "Registry::HKEY_CLASSES_ROOT\CLSID\$g" -ErrorAction SilentlyContinue)."(default)"
    Write-Host "   $g  =>  $n"
  }
}
```

输出中 `=> WPS网盘` 的就是目标（形如 `{5FCD4425-CA3A-48F4-A57C-B8A75C32ACB1}  =>  WPS网盘`）。

### 第 2 步：备份 → 删除 → 通知系统刷新

> 先把下面两个 GUID 换成第 1 步在你机器上查到的。

```powershell
$mc = "HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\MyComputer\NameSpace"
$dt = "HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\Desktop\NameSpace"

# 1) 备份（还原时双击 .reg 导入即可）
reg export "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\MyComputer\NameSpace" "$env:USERPROFILE\Downloads\MyComputer-NameSpace-backup.reg" /y
reg export "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Desktop\NameSpace" "$env:USERPROFILE\Downloads\Desktop-NameSpace-backup.reg" /y

# 2) 删除 WPS 的两个 GUID 子项
Remove-Item "$mc\{5FCD4425-CA3A-48F4-A57C-B8A75C32ACB1}" -Recurse
Remove-Item "$dt\{7AE6DE87-C956-4B40-9C89-3D166C9841D3}" -Recurse

# 3) 通知资源管理器刷新（免重启 explorer，实测立即生效）
Add-Type -MemberDefinition '[DllImport("shell32.dll")] public static extern void SHChangeNotify(int wEventId, uint uFlags, IntPtr dwItem1, IntPtr dwItem2);' -Name ShellNotify -Namespace Win32
[Win32.ShellNotify]::SHChangeNotify(0x08000000, 0, [IntPtr]::Zero, [IntPtr]::Zero)
```

### 第 3 步：验证

打开文件资源管理器，导航窗格里"WPS网盘"应已消失；也可以用命令确认：

```powershell
Test-Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\MyComputer\NameSpace\{5FCD4425-CA3A-48F4-A57C-B8A75C32ACB1}"   # 应为 False
Test-Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\Desktop\NameSpace\{7AE6DE87-C956-4B40-9C89-3D166C9841D3}"     # 应为 False
```

## 五、注意事项与善后

### 1. 后台进程 wpscloudsvr.exe

删完注册表后，WPS 的后台云服务进程 `wpscloudsvr.exe` 可能仍在运行（它是网盘的后端）。普通权限下结束它会被拒绝（**Access is denied**，该进程以系统账户运行），需要管理员权限：

```powershell
# 需在管理员 PowerShell 中执行
Stop-Process -Name wpscloudsvr -Force
```

它没有任何界面，对应的系统服务是"**手动 + 已停止**"，**开机不会自启**，只有打开 WPS 时才可能被拉起。不想折腾的话重启一次电脑即可清掉。

### 2. 图标将来可能"复活"

WPS 在运行或更新时，可能会把这两个注册表项**重新写回**。如果哪天图标又出现了：

- 简单处理：按上面流程再删一次；
- 根治处理：去 WPS 里从源头关闭 —— 打开 WPS，**首页 → 右上角全局设置（齿轮）→ 设置中心**，找到"在'此电脑'中显示 WPS 网盘 / 云文档入口"之类的开关关掉（不同版本措辞略有差异）。

### 3. 如何还原

双击之前导出的备份 `.reg` 文件，确认导入即可恢复删除的项。

### 4. 其他相关项（可选）

- 计划任务 `WpsUpdateTask_<用户名>`：WPS 的自动更新任务，与网盘无直接关系，介意的话可在"任务计划程序"中禁用。
- 自启动：`HKCU\...\Run` 下如出现 WPS 相关的启动项，可顺手删除。

- 实际删除的项：
  - `HKCU\...\Explorer\MyComputer\NameSpace\{5FCD4425-CA3A-48F4-A57C-B8A75C32ACB1}`

- 复查两次，注册表项未被 `wpscloudsvr.exe` 写回；
- `HKLM` 下的两个 NameSpace 路径均无 WPS 项，未做改动。
