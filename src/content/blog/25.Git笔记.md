## Git 初始化

1. 初始化身份

   ```bash
   git config --global user.name "dongyue"
   git config --global user.email "2436847447@qq.com"
   ```

2. 新版的 Git 默认分支名是 `master`，但 GitHub 和 GitLab 已经改用 `main`，建议统一：

   ```bash
   git config --global init.defaultBranch main
   ```

3. 也可以将当前分支名从 master 改为 main：

   ```bash
   git branch -m main
   ```

4. 用 SSH 方式连接 GitHub/GitLab 可以免密推送：

   ```bash
   ssh-keygen -t ed25519 -C "2436847447@qq.com"
   cat ~/.ssh/id_ed25519.pub
   ```

## Git 仓库

1. 初始化

   ```bash
   git init
   ```

2. 添加远程仓库

   ```bash
   git remote -v                         # 查看远程仓库列表
   git remote add origin <地址>           # 添加远程仓库
   git remote set-url origin <新地址>     # 修改远程地址
   git remote rm origin                  # 删除远程关联
   ```

   直接编辑 `.git/config` 文件这是最直接的方法。你可以手动编辑项目根目录下的 `.git/config` 文件，为同一个远程仓库名（remote）配置多个 `url`：

   ```ini
   [remote "all"]
       url = git@github.com:user/repo.git
       url = git@gitee.com:user/repo.git
   ```
