title: 'Windows常用快捷操作整理'
pubDate: '2026-09-22'
---

*   **Win + E**：打开文件资源管理器（快速访问文件和文件夹）。
*   **Win + D**：显示或隐藏桌面，快速清理屏幕上的所有窗口。
*   **Win + L**：锁定计算机，保护你的隐私和数据。
*   **Win + R**：打开“运行”对话框，快速启动程序或打开文件。
*   **Win + M**：最小化所有窗口，只显示桌面。
*   **Win + Shift + M**：还原之前最小化的所有窗口。
*   **Win + Tab**：使用任务视图切换窗口，预览和管理打开的应用和窗口。
*   **Win + V**（Windows 10及以后）：打开剪贴板历史记录，快速访问复制过的内容。
*   **Win + 加号键** 和 **Win + 减号键**：放大或缩小当前页面或屏幕，辅助视力不佳的用户。
*   **Win + 方向键**：调整窗口大小或移动窗口（左、右、上、下）。
*   **Alt + F4**：关闭当前程序或窗口。
*   **Alt + Enter**：在文件资源管理器中查看文件或文件夹的属性。
*   **F11**：全屏化当前浏览器窗口（大多数浏览器支持）。 **1\. 基础系统操作**
*   **Win + E**：打开文件资源管理器（快速访问文件和文件夹）。
*   **Win + D**：显示或隐藏桌面，快速清理屏幕上的所有窗口。
*   **Win + L**：锁定计算机，保护你的隐私和数据。
*   **Win + R**：打开“运行”对话框，快速启动程序或打开文件。
*   **Win + M**：最小化所有窗口，只显示桌面。
*   **Win + Shift + M**：还原之前最小化的所有窗口。
*   **Win + Tab**：使用任务视图切换窗口，预览和管理打开的应用和窗口。
*   **Win + X**：打开Windows快速链接菜单，快速访问电源选项、设备管理器等。
*   **Win + PrtSc**（Windows 10及以后）：将整个屏幕的截图保存为文件。
*   **PrtSc**（Print Screen）：复制整个屏幕的截图到剪贴板。
*   **Alt + PrtSc**：仅复制当前活动窗口的截图到剪贴板。
*   Ctrl + Home/End\*\*：在文本编辑器中快速将光标移动到文件头或文件尾。 **2\. 文本编辑与浏览**
*   **Ctrl + S**：保存文件或当前工作。
*   **Ctrl + N**：新建文件或窗口。
*   **Ctrl + O**：打开文件或窗口。
*   **Ctrl + Z**：撤销上一步操作。
*   **Ctrl + F**：查找文件或内容。
*   **Ctrl + X**：剪切选定的内容或文件。
*   **Ctrl + C**：复制选定的内容或文件。
*   **Ctrl + V**：粘贴内容或文件。
*   **Ctrl + B/I/U**：加粗、斜体、下划线文本（在文本编辑器中）。
*   **Ctrl + Shift**：切换输入法（需结合其他键使用）。
*   **Ctrl + 空格**：中英文输入法切换。
*   **F5**：刷新页面或窗口。
*   **Ctrl + F5**：在浏览器中强行刷新页面，忽略缓存。
*   **Ctrl + Home/End**：在文本编辑器中快速将光标移动到文件头或文件尾。 **3\. 窗口与导航**
*   **Alt + F4**：关闭当前程序或窗口。
*   **Alt + Tab**：在打开的程序或窗口间切换。
*   **Alt + 空格 + C/N/R/X/M/S**：在窗口标题栏上按Alt + 空格后，可使用这些键关闭、最小化、恢复、最大化、移动或改变窗口大小。
*   **Win + G**（Windows 10及以后）：打开游戏栏，用于录屏、截图等。
*   **Win + V**（Windows 10及以后）：打开剪贴板历史记录，快速访问复制过的内容。
*   **Win + Shift + S**（Windows 10及以后）：启动截图工具，可选择区域截图。 **4\. 浏览器操作**
*   **Ctrl + T**：在浏览器中打开新标签页。
*   **Ctrl + W** 或 **Ctrl + F4**：关闭当前浏览器标签页。
*   **Ctrl + Shift + T**：恢复最近关闭的标签页（大多数现代浏览器支持）。
*   **Ctrl + 数字键**：快速切换到指定序号的标签页。
*   **Ctrl + D**：将当前页面添加到书签。
*   **Ctrl + H**：打开浏览器历史记录。
*   **F11**：全屏化当前浏览器窗口（大多数浏览器支持）。 **5 辅助功能**
*   **Win + 加号键** 和 **Win + 减号键**：放大或缩小当前页面或屏幕，辅助视力不佳的用户。
*   **Win + 方向键**：调整窗口大小或移动窗口（左、右、上、下）。
*   **Alt + Enter**：在文件资源管理器中查看文件或文件夹的属性。
