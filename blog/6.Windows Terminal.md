## Windows Terminal 完整快捷键参考：

### 标签页

*   `Ctrl + Shift + T` — 新建标签页
*   `Ctrl + Tab` — 切换到下一个标签页
*   `Ctrl + Shift + Tab` — 切换到上一个标签页
*   `Ctrl + Alt + 数字键` — 切换到第 N 个标签页
*   `Ctrl + Shift + W` — 关闭当前窗格/标签页

### 分屏窗格

*   `Alt + Shift + D` — 垂直分屏（左右）
*   `Alt + Shift + -`（减号）— 水平分屏（上下）
*   `Alt + Shift + +`（加号）— 再次垂直分屏（重复当前分割方向）
*   `Alt + 方向键` — 在窗格间移动焦点
*   `Alt + Shift + 方向键` — 调整窗格大小
*   `Ctrl + Shift + Space` — 全屏切换当前窗格

### 交换窗格位置（需手动配置）

默认无快捷键，需在 settings.json 中添加：

```json
{ "command": { "action": "swapPane", "direction": "up" }, "keys": "ctrl+shift+up" },
{ "command": { "action": "swapPane", "direction": "down" }, "keys": "ctrl+shift+down" },
{ "command": { "action": "swapPane", "direction": "left" }, "keys": "ctrl+shift+left" },
{ "command": { "action": "swapPane", "direction": "right" }, "keys": "ctrl+shift+right" },
```

也可用 `Ctrl+Shift+P` 打开命令面板搜索 "Swap Pane"。

### 搜索与查找

*   `Ctrl + Shift + F` — 打开搜索框
*   `Ctrl + Shift + D` — 重复搜索匹配项（在搜索结果中向下跳转）

### 外观

*   `F11` — 全屏切换
*   `Ctrl + Shift + ,` — 打开设置
*   `Ctrl + Shift + P` — 打开命令面板
*   `Alt + Enter` — 全屏切换
