---
title: 'Winget 换源'
pubDate: '2026-09-08'
category: system
tags: [winget, windows, mirror]
description: 把 Winget 的软件源换成国内镜像，下载和更新都能快不少。
---

先删除原 WinGet 源：

```
winget source remove winget 
```

然后添加南京大学镜像：

```
winget source add winget https://mirror.nju.edu.cn/winget-source 
```

以后如果要重置为默认源，请输入命令：

```
winget source reset winget
```
